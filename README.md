# EQ Lab

휴대폰 이퀄라이저 앱의 0단계 기술 검증용 테스트 앱입니다. 갤럭시 S22 울트라(One UI 8.0, Android 16)에서
유튜브 뮤직 소리에 EQ를 걸 수 있는지 확인합니다.

## 화면

1. 기기 정보: 모델, Android 버전, 출력 장치, 기기에 등록된 오디오 효과 목록
2. 세션 감시 (실험 A): 음악 앱이 공개하는 오디오 세션과 재생 정보를 기록
3. 효과 적용 (실험 A·B): 세션이나 전역(0번)에 10밴드 EQ를 걸고 귀로 확인. 내장 테스트음으로 대조 시험
4. 스펙트럼 (실험 C): 다른 앱 재생음을 캡처해 10밴드 스펙트럼 표시
5. 결과 기록: 앱 x 실험 x 출력 장치별 결과를 저장하고 복사

## 빌드

GitHub Actions가 push할 때마다 디버그 APK를 빌드해 Releases에 올립니다.
